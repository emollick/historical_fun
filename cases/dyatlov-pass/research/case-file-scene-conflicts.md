# Dyatlov Pass, 1959 criminal case file: SCENE and SEARCH - contradictions between documents and EN/RU translation divergences

Companion to case-file-scene-facts.md (fact numbers F1-F246 refer to that file). Sources: dyatlovpass.com transcriptions, EN https://dyatlovpass.com/case-files-SLUG?rbid=17743 and RU https://dyatlovpass.com/case-files-SLUG-ru?rbid=17747 (scans at https://dyatlovpass.com/gallery-case-files-SLUG). "sh." = лист of the case file. Where a conflict is between witnesses' recollections given weeks apart it is listed as such; where it is between two formal documents it is flagged "document vs document".

## Part C. Site commentary encountered (marked as site opinion, not used as fact)

- Introductions on several pages (e.g. sh. 29-30) state that the second diary is not Kolmogorova's; the case file itself (sh. 6) labels it "Дневник Колмогоровой".
- Captions on the photo-table pages (sh. 388-392) are the expert's; surrounding remarks are the site's.
- The site's English introductions to the radiograms sometimes date or attribute messages; the fact table uses only the dates written in the radiogram texts.
