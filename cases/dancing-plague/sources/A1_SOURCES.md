# A1_SOURCES.md — index of raw sources retrieved

Fetch date for everything below: 2026-09-14 (all via archive.org unless stated). Companion analysis: `../notes/A1_council_record.md`.

Verification legend used in the notes: **[IMG]** = transcription checked against the page image saved here; **[OCR]** = read only in the archive.org OCR text (djvu.txt); **[2ND]** = known only through a secondary work; **[UNVERIFIED (from memory)]** = not retrieved.
